This is a simple, open and free MD to PHP form converter with some automatic grading features. 

<img width="640" height="480" alt="quizMaker" src="https://github.com/user-attachments/assets/124bb879-aae5-4cbd-aa90-bb92f865c272" />

```
Markdown parser
# / ## / ### ...            -> headers
**bold line**               -> instruction text (below header, not in list)
**bold** / *italiac*        -> regular styling (in questions)
N. ... _|answer|_ ...       -> fill-in question 
N. prompt — |OPT1| / OPT2   -> select question 
```
